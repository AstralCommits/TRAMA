# test(integration): cobrir fluxos principais da TRAMA com a API

**Prioridade:** Alta  
**Relações/dependências:** Depende dos endpoints e ambiente de teste; relaciona-se às issues FE-13 a FE-23.

## Objetivo
Criar testes automatizados que protejam os contratos e os fluxos principais da TRAMA.

## Cobertura mínima
- [ ] Login e requisição autenticada.
- [ ] Categorias e confecções.
- [ ] Lançamento mensal e validação de duplicidade.
- [ ] Importação CSV e erros por linha.
- [ ] Indicadores e filtros.
- [ ] Tendências e comparação de períodos.
- [ ] Simulação e persistência de cenários.
- [ ] Respostas 400, 401, 403, 404, 500 e falha de rede.
- [ ] Permissões e isolamento de dados por organização, quando implementados.
- [ ] Instruções para executar os testes no README.
- [ ] Dados de teste fictícios, sem dados pessoais/comerciais reais.
