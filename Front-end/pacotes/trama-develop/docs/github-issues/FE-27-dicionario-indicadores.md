**Prioridade:** Média  
**Relações/dependências:** Pode ser desenvolvido após validação das fórmulas oficiais.

Explicar indicadores em português simples para pessoas com diferentes níveis de familiaridade com dados.

- [ ] Explicar faturamento, quantidade, valor médio por peça e tendência.
- [ ] Mostrar fórmula e unidade de cada indicador.
- [ ] Informar período e origem dos dados.
- [ ] Diferenciar comparação histórica de previsão.
- [ ] Usar exemplos demonstrativos claramente rotulados.
- [ ] Validar textos com equipe/professor e, se possível, usuários.
