# FE-28 — Filtros salvos por usuário

> Identificador interno do backlog de implementação. Não equivale ao número de uma issue oficial do GitHub.

## Objetivo

Salvar filtros de contas reais no servidor, isolando por usuário; manter modo demonstração local claramente identificado.

## Critério de aceite consolidado

Um usuário salva e recupera seus filtros após novo login; outro usuário não acessa os filtros alheios.

## Validação necessária

Testar persistência com dois usuários, logout/login, limpeza e acesso negado.
