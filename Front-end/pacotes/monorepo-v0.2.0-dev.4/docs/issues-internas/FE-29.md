# FE-29 — Equipe, convites e auditoria

> Identificador interno do backlog de implementação. Não equivale ao número de uma issue oficial do GitHub.

## Objetivo

Permitir membros com perfil FUNCIONARIO, convites de uso único com expiração, revogação, aceite e trilha de auditoria. O token deve ser compartilhado manualmente se não houver serviço de e-mail.

## Critério de aceite consolidado

Convite válido pode ser aceito uma única vez antes de expirar; convite revogado/expirado não é aceito; funcionário fica no escopo da confecção.

## Validação necessária

Testar token duplicado/concorrrente, expirado, revogado, usuário de outra empresa e trilha de auditoria em MySQL.
