# FE-21 — Tratamento centralizado de erros HTTP

> Identificador interno do backlog de implementação. Não equivale ao número de uma issue oficial do GitHub.

## Objetivo

Padronizar mensagens, expiração de sessão, falha de rede e recuperação manual; não repetir automaticamente operações que possam duplicar gravações.

## Critério de aceite consolidado

Erros de validação, autenticação, autorização, conflito, limite de arquivo e servidor são comunicados de forma compreensível.

## Validação necessária

Executar matriz 400/401/403/404/409/413/5xx, timeout e desconexão; conferir ações mutáveis sem retry automático.

## Situação na consolidação v0.2.0-dev.4

**Tratamento de status implementado; matriz contra API real pendente.**

O cliente agora diferencia 400/422, 401, 403, 404, 409, 413, 429 e 5xx, além de timeout, cancelamento e falha de rede. Operações de escrita não são repetidas automaticamente.

A classificação “implementado no código” não representa, por si só, execução de testes completos ou aprovação final do critério de aceite. Consulte `../AUDITORIA-FE-13-A-FE-31-v0.2.0-dev.4.md` e `../QA-RESULTADOS-v0.2.0-dev.4.md`.
