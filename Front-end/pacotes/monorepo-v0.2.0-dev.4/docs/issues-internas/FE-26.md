# FE-26 — Histórico de importações

> Identificador interno do backlog de implementação. Não equivale ao número de uma issue oficial do GitHub.

## Objetivo

Listar importações realizadas pelo usuário/escopo permitido com arquivo, data, quantidade de linhas e status, incluindo falhas.

## Critério de aceite consolidado

Após uma importação bem-sucedida ou com erro, o histórico mostra o resultado sem expor importações de outra confecção.

## Validação necessária

Testar arquivo válido, inválido, vazio, duplicado, falha transacional e escopo de funcionário.
