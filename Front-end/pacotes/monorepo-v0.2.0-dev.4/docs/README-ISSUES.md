# Como ler o inventário de issues

- `ISSUES-GITHUB-OFICIAIS-2026-11-23.md` contém os 22 números reais do GitHub e seu estado observado.
- `issues-github/` contém um registro individual das 22 issues oficiais, com link para o texto integral no GitHub e síntese de escopo/estado.
- `issues-internas/FE-13.md` a `FE-31.md` são os 19 documentos internos do backlog de implementação; não são números de issue GitHub.
- A auditoria das FE-13..FE-31 aponta o que está no código e o que ainda exige validação.

A inclusão de uma issue no pacote não altera seu estado no GitHub.
